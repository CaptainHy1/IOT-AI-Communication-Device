HƯỚNG DẪN TRIỂN KHAI CHI TIẾT ICD
--------------------------------

BƯỚC 1: CÀI ĐẶT MÔI TRƯỜNG
- Cài Python 3.10+ cho Backend.
- Cài VS Code + Cursor + PlatformIO (hoặc Arduino IDE) cho ESP32.

BƯỚC 2: TRIỂN KHAI BACKEND (Dùng Prompt số 2)
- Chạy lệnh: pip install fastapi uvicorn openai websockets python-dotenv
- Tạo file .env và dán OPENAI_API_KEY của bạn vào.
- Chạy server: "uvicorn main:app --host 0.0.0.0 --port 8000"
- Ghi lại địa chỉ IP của máy tính (ví dụ: 192.168.1.15).

BƯỚC 3: LẮP RÁP PHẦN CỨNG
- Đấu nối theo đúng sơ đồ chân trong Prompt số 3.
- CẢNH BÁO: Kiểm tra kỹ chân 5V và 3.3V. Đừng cắm nhầm nguồn cho OLED và Mic (chỉ dùng 3.3V).
- Thêm tụ hóa 1000uF vào nguồn VIN của ESP32 để lọc nhiễu cho loa.

BƯỚC 4: NẠP CODE ESP32 (Dùng Prompt số 3)
- Thay đổi tên WiFi, Mật khẩu và IP Server trong code mà Cursor vừa tạo.
- Nạp code và mở Serial Monitor để theo dõi log.

BƯỚC 5: KIỂM TRA
- Nhấn giữ nút Flash trên ESP32 và nói "Xin chào".
- Quan sát OLED chuyển sang "SUY NGHĨ".
- Nghe câu trả lời từ loa.

Kiểm tra sau sửa:

Không có linter error ở các file đã chỉnh.
python -m compileall cho BE chạy OK (không lỗi syntax).
Gợi ý bước tiếp theo để chạy thực tế với ESP32:

Cài lại package: pip install -r BE/requirements.txt
Đảm bảo máy có Ollama + model mistral đang chạy (http://localhost:11434).
Chạy BE và test từ ESP32 gửi PCM16 mono 16kHz vào /ws/chat với event end hoặc end_of_audio.
